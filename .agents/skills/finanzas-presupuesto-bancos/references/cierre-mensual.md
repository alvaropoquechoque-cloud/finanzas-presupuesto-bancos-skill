# Cierre mensual

## Objetivo

Validar que el mes financiero de Sommos esté completo, conciliado y listo para análisis.

## Checklist

1. Confirmar que las transacciones del mes estén completas.
2. Revisar movimientos `Por categorizar`.
3. Validar tipos de cambio.
4. Confirmar estados `Pagado/Cobrado` y `Pendiente`.
5. Conciliar todas las cuentas bancarias con actividad.
6. Investigar diferencias bancarias.
7. Revisar CxC pendientes y vencidas.
8. Revisar CxP pendientes y vencidas.
9. Comparar presupuesto vs ejecución real.
10. Revisar burn.
11. Validar `Runway Mensual`.
12. Validar `Dashboard`.
13. Buscar errores como `#REF!`, `#VALUE!` o `#N/A`.

## Reglas

No cerrar un mes mediante ajustes artificiales.

Una diferencia debe explicarse con evidencia.

No convertir obligaciones pendientes en realizadas solo para cerrar el mes.

No modificar saldos bancarios reales para coincidir con el cálculo.

## Resultado esperado

El cierre debe permitir distinguir claramente:

- caja real
- ingresos realizados
- egresos realizados
- CxC
- CxP
- presupuesto
- proyección
